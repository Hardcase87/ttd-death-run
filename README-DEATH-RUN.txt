TTD: DEATH RUN // VERTICAL SLICE 01

GOAL
A standalone Godot/Xogot project foundation for a side-scrolling TTD action game.
Hybrid visual target: Broforce-like readable gameplay + premium TTD/VHS presentation.

CURRENT SLICE
- Hardcase '87 placeholder gameplay body
- Left/right movement
- Jump
- Smash attack
- Side-scrolling camera
- VHS Quarter test strip
- Basic TDI enemies
- Health / lives / score
- TBN LIVE broadcast HUD
- Stage progression skeleton (1-8)
- Desktop controls
- Mobile control artwork ready for touch wiring

CONTROLS
A / Left Arrow  = move left
D / Right Arrow = move right
Space           = jump
J               = smash

NEXT BUILD
1. Proper Xogot touch input
2. Hardcase animated sprite system
3. Camera impact shake
4. Breakable props / VHS crates
5. First TBN executioner mini-boss
6. Character select hooks for Viper and Captain Calorie
7. Stage 1 visual asset pass

REPO RECOMMENDATION
ttd-death-run

UPLOAD THE ENTIRE PROJECT FOLDER TO THE REPO.
Then import/open project.godot in Xogot.

DESIGN RULE
Do NOT chase poster-level detail every gameplay frame.
Use clean chunky gameplay sprites + richer backgrounds/VFX/menus/boss splashes.
